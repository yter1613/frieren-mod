# 🪄 Frieren: Beyond Journey's End Mod (Minecraft Fabric 1.20.4)

[![Minecraft Fabric](https://img.shields.io/badge/Minecraft-1.20.4-blue.svg)](https://minecraft.net/)
[![Fabric Loader](https://img.shields.io/badge/Fabric-Loader-green.svg)](https://fabricmc.net/)

A custom Minecraft Fabric mod inspired by the anime **"Frieren: Beyond Journey's End"** (*Sousou no Frieren*). Step into the shoes of a mage, explore legendary structures, master ancient spells, and embark on a cinematic journey to defeat the Ender Dragon!

---

## ✨ Features

- **🏰 The Abandoned Church of Frieren**
  - Spawns naturally during world generation.
  - Contains Frieren's staff and a testamentary book guiding your path.
- **🌳 The Great Tree Dungeon**
  - A massive 50-block procedural giant tree structure hidden in the world.
  - Multi-level vertical dungeon featuring spider spawners, custom traps (watch out for the TNT!), and a cozy living room at the top (`Y=42`) with guaranteed magic focuses and loot chests.
- **🔮 Unique Magic System**
  - **Zoltraak** — Offensive piercing magic.
  - **Shield** — Defensive barrier.
  - **Heal** — Restoration and recovery.
  - **Flight** — Levitation and mobility.
  - **Dig** — Utility mining spell.
  - **Flower Field** (`/flowerfield`) — Ultimate reward spell unlocked after defeating the Ender Dragon.

---

## 📦 Requirements & Tech Stack

- **Minecraft Version:** `1.20.4`
- **Mod Loader:** `Fabric Loader` & `Fabric API`
- **Visual Enhancements (Recommended):** 
  - *Sodium* & *Iris Shaders* (for cinematic Ray Tracing / Path Tracing lighting)
  - *Replay Mod* (for recording cinematic camera paths)

---

## 🚀 Installation

1. Make sure you have **Minecraft 1.20.4** installed with **Fabric Loader**.
2. Download the latest release or clone this repository.
3. Build the mod using Gradle or place the source into your development environment (`IntelliJ IDEA`).
4. Drop the compiled `.jar` file into your `mods` folder along with the *Fabric API*.
